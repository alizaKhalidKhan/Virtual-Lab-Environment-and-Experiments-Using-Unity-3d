# Virtual-Lab-Environment-and-Experiments-Using-Unity-3d

I developed a 3D Virtual Labs environment in Unity, leveraging Asset Store assets, to align with the academic objectives of the Final Year Project. This immersive platform features interactive Chemistry and Physics labs, meticulously designed to mirror the BSEK and BIEK curriculum and textbooks. Guided lab instructions are provided through on-screen English text and Urdu voice narration, complemented by integrated audio elements. Realistic lab interactions are enabled through intuitive player movement, UI panels, triggers, and colliders. The environment ensures seamless cross-platform compatibility across VR devices, mobile, and desktop web platforms. Additionally, I contributed to designing a bio environment, further enriching the virtual lab experience.
